Agent · 预测模型

MatchEdge · 足彩分析 Agent

核心是 Agent + 预测模型：Agent 负责理解中文提问、联网查伤停、按「八步法」逐场研判； 预测模型负责给出每场主胜 / 平局 / 客胜的概率，并与市场概率并排呈现在预测看板上。

  1. 一
    期望进球用泊松回归估计双方的期望进球。
  2. 二
    市场共识将七家机构赔率去除抽水（庄家利润）后取中位数，得到市场共识概率， 再用岭回归对共识做修正。
  3. 三
    辅助信号融入澳门盘口深浅变化，作为辅助信号。

本项目仅供学习与研究交流，预测结果不构成任何投注建议。

Python · 自动化

UIUC MediaSpace 视频下载器

一个面向学校 MediaSpace（Kaltura）平台的无头批量下载脚本：给它一个频道地址， 它会把频道里的课程视频逐个找出来并下载到本地。

  1. 一
    扫描频道Selenium 驱动无头 Chrome 打开频道页，筛出所有有效的视频页链接。
  2. 二
    嗅探流地址模拟点击播放，从浏览器性能日志里抓取真实的视频流地址。
  3. 三
    下载落盘交给 yt-dlp 下载并按视频标题命名保存。

小彩蛋：仓库里的目标站点配置用 AES-128 加密，需要先解开 README 里的小谜题才能使用。
